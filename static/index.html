MCP 接入配置 · Streamable HTTP

在 MCP 客户端选择「Streamable HTTP」，填写下面的服务地址。MCP 随服务一同启动，与网页共用端口，无需独立进程；不使用旧版 /sse 地址。


      
上方为常见 mcpServers 格式示例，配置字段以客户端要求为准。远程访问时使用服务器地址，并确保 listen 绑定到可达地址；本机地址 127.0.0.1 只适用于同一台电脑。

      
读取工具：list_connections、list_databases、list_keys、get_value、export_key。先使用 list_connections 选择 connection；多个连接时必须指定名称。

      
delete_key 仅在 allow_delete 开启时提供。删除失败或超时后先核对 key 状态，不要自动重试。

      
list_keys 和 get_value 使用返回的 cursor 翻页；SCAN 中间页可能为空，cursor 为 null 时结束。二进制 key 使用 key_b64，值按需以 Base64 返回。

      
服务无内置登录，远程接入应配置认证代理或网络访问控制。
